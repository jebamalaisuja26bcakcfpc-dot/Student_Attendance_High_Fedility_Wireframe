📌 Project Overview

The Student Attendance Management System is a modern UI/UX design created in Figma to manage student attendance efficiently. The system provides separate interfaces for HOD, Class Teachers, and Students.

🎯 Objective

To simplify student attendance management.
To provide quick access to attendance records.
To display attendance percentage clearly.
To manage students, faculty, and classes.
To generate and view attendance reports.
To provide a simple and user-friendly interface.

👥 User Roles

HOD (Head of the Department)
Class Teacher
Student

✨ Key Features

HOD Dashboard
Total Faculty
Total Students
Overall Attendance Rate
